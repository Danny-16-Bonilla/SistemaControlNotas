# 📂 Centro de Documentación del Sistema SGCE

Bienvenido al centro principal de documentación del **Sistema de Gestión y Control de Notas Estudiantiles (SGCE)**. En este directorio se centralizan la especificación de requisitos, las historias de usuario, los registros de decisiones técnicas y los manuales operativos.

---

## 🗺️ Estructura de la Documentación

Haga clic en cualquiera de las secciones para acceder directamente a los documentos:

### 📑 1. Análisis y Arquitectura
* **[📋 Requisitos Funcionales y No Funcionales](./requisitos/)**: Especificación formal de requisitos (`RF-01` a `RF-17`) y atributos de calidad (`RNF-01` a `RNF-10`).
* **[📖 Historias de Usuario](./historias_usuario/)**: Historias ágiles de desarrollo (`HU-01` a `HU-10`) con criterios de aceptación e estimación.
* **[🏛️ Registros de Decisión de Arquitectura (ADR)](./adr/)**: Bitácora de decisiones sobre arquitectura, framework, base de datos y seguridad.
