## 1. Objetivo del Sistema
Centralizar y automatizar el registro, seguimiento y reporte de calificaciones universitarias para erradicar inconsistencias del registro manual y garantizar la trazabilidad académica.

## 2. Acceso al Sistema
1. Abra el navegador e ingrese la URL oficial del sistema.
2. Digite su correo institucional y contraseña.
3. Presione **"Iniciar Sesión"**.

## 3. Roles de Usuario
* **Estudiante:** Consulta notas, promedios y gestiona revisiones.
* **Docente:** Configura rubros evaluativos e ingresa calificaciones.
* **Administrador:** Gestiona periodos, asignaturas y cuentas de usuario.

## 4. Funcionalidades Principales
* Ingreso de notas por rubro evaluativo (`HU-04`).
* Consulta en tiempo real de calificaciones desglosadas (`HU-06`).
* Generación de reportes institucionales (`HU-10`).

## 5. Pasos para usar dos funcionalidades

### 🔹 Funcionalidad 1: Ingreso de Notas (Docentes)
1. Navegue a **"Mis Cursos"** y elija la asignatura.
2. Seleccione la evaluación a calificar (ej. *Parcial 1*).
3. Digite las notas numéricas (rango 0-100).
4. Guarde cambios. El promedio se actualizará automáticamente.

### 🔹 Funcionalidad 2: Consulta de Notas (Estudiantes)
1. Ingrese a **"Mis Calificaciones"**.
2. Seleccione el periodo lectivo.
3. Revise la lista de componentes, notas obtenidas y promedio ponderado actual.

## 6. Mensajes Comunes
* `Credenciales inválidas`: Correo o contraseña incorrectos.
* `Acta cerrada`: El periodo de notas venció. Contacte al administrador para una reapertura.

## 7. Preguntas Frecuentes (FAQ)
* **¿Qué hago si mi nota digitada es incorrecta?**  
  Si el acta aún está abierta, el docente puede modificarla directamente en el sistema. Si el acta ya se cerró, el estudiante debe solicitar una revisión desde el apartado de consulta para habilitar el flujo formal.
  Contacte al profesor o envíe una solicitud en el menú *'Solicitar Revisión'*.
